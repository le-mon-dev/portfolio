# roblox

Roblox Studio로 만든 게임 맵과 캐릭터 애니메이션입니다.

## places/ (게임 맵, `.rbxl`)

| 파일 | 내용 |
|---|---|
| `ChooseYourPower_OldMap.rbxl` | Choose Your Power(CYP) 초기 맵. 유튜브 쇼츠 「게임을 5배속 하면 일어나는 일」 배경 |
| `Forsaken.rbxl` | Forsaken 스타일 맵 |
| `enemies.rbxl` | 적 캐릭터 테스트 맵 |
| `sad.rbxl` | 애니메이션 촬영용 맵 |

## animations/ (`.rbxm`)

| 파일 | 내용 |
|---|---|
| `two_time.rbxm` | 캐릭터 애니메이션 |
| `Penguin.rbxm` | 「애니메이팅 – 펭귄」(Club Penguin Pizzatron 4000 오마주) 리그 |

## models/

애니메이션 작업에 사용한 리그·파티클·소품 모델 (`WardenRig`, `DeluxeRevolver`, `Moss`, `ParticlePacks`).

완성 영상은 YouTube 채널 [Le_몬](https://www.youtube.com/@Le_%EB%AA%AC)에서 볼 수 있습니다.
