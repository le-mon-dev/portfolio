# algorithms

정보올림피아드 문제를 Python으로 직접 풀어 본 코드입니다. 공식 해설 코드와 채점 데이터는 포함하지 않았습니다.

## 세종 정보올림피아드 제3회 (`sejong-olympiad-3rd/`)

| 파일 | 내용 |
|---|---|
| `P01.py`, `P01.cpp` | 단가 × 수량 합계 (같은 문제를 Python과 C++로) |
| `P02.py` | 두 상품의 가격·수량을 입력받아 총액 계산 |
| `P03.py` | 총액이 10,000 이상이면 1,000 할인 |
| `P04.py` | N개 상품의 가격·수량 벡터 내적 |
| `P05.py` | 다이얼 비밀번호를 맞추기 위한 최소 회전 횟수 (10진 순환 거리) |
| `P06.py` | 2, 3, 4의 합으로 N을 만드는 경우의 수 (3중 반복 완전탐색) |
| `P07.py` | 점수 구간별 등급(A~D) 판정과 상금 합계 |
| `P08.py` | 트리(N-1개 간선)의 지름 구하기 (거리 행렬 반복 완화) |

## KOI 지역예선 (`koi-20xx/`)

| 파일 | 문제 | 접근 |
|---|---|---|
| `koi-2020/calabash.py` | 조롱박 나누기 | 1..k 최소 배분 후 남는 개수를 뒤에서부터 순환 분배 |
| `koi-2021/erase.py` | 지우기 | 절반씩 줄여 가며 남는 번호 시뮬레이션 |
| `koi-2021/division.py` | 4등분 | 세 개의 분할점을 3중 반복으로 완전탐색 |
| `koi-2022/bread.py` | 빵 | 조건을 만족하는 최소값 탐색 |
| `koi-2023/cream_bread.py` | 크림빵 | k개 묶음마다 0의 개수를 세어 조건 판정 |
| `koi-2023/shelter.py` | 대피소 | k(≤3)개 대피소 위치를 완전탐색하며 맨해튼 거리의 최대값 최소화 |
